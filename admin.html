หลังบ้าน Koong Tung

เข้าสู่ระบบด้วย GitHub Access Token เพื่อแก้ไขเมนู ราคา และรูปภาพ

สร้าง Token แบบจำกัดสิทธิ์เฉพาะ repo นี้ (ปลอดภัยสุด):
  1. ไปที่ github.com/settings/personal-access-tokens/new (ต้อง login ด้วยบัญชี koongtung ก่อน)
  2. Token name: ใส่ว่า koongtung-menu-admin
  3. Expiration: เลือกตามสะดวก (แนะนำ 1 ปี แล้วค่อยสร้างใหม่)
  4. Repository access: เลือก "Only select repositories" → เลือก koongtung-menu
  5. Permissions → Repository permissions → Contents → เปลี่ยนเป็น Read and write
  6. กด Generate token ด้านล่างสุด แล้วคัดลอกโทเคน (ขึ้นต้นด้วย github_pat_) มาใส่ในช่องด้านบน
คำเตือน: อย่าแชร์ token นี้ให้ใครที่ไม่ใช่แอดมิน เพราะเทียบเท่ารหัสผ่านที่แก้เว็บได้ ระบบเก็บ token ไว้ในเบราว์เซอร์นี้เท่านั้น ไม่ได้ส่งไปที่ไหนอื่นนอกจาก GitHub โดยตรง
